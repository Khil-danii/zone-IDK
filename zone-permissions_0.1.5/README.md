# Zone Permissions — Factorio 2.1

Прямоугольные зоны с дополнительными ограничениями для существующих групп
разрешений Factorio. Версия мода: **0.1.5**.

## Настройка

1. Установите `zone-permissions_0.1.5.zip` в папку `mods` и включите мод.
2. Администратор создаёт группы и назначает игроков через `/permissions`.
   Названия произвольные: например, «Гости», «Участники», «Строители».
3. Команда `/zone-tool` выдаёт инструмент. Выделите прямоугольник на нужной поверхности.
4. Откройте `/zone-gui`, нажмите **«Права групп»** у зоны и сохраните настройки.

Новые зоны закрыты для всех, включая создавшего их администратора.
Существующие закрытые зоны после обновления сохраняют ограничения.

## Правила групп

| Право | Что контролируется |
|---|---|
| Строить объекты | Строительство зданий и размещение их призраков чертежами |
| Демонтировать | Ручная добыча объектов, удаление призраков, выдача приказов демонтажа |
| Взаимодействовать | Открытие зданий, быстрый перенос предметов, поворот, отражение, обычное копирование/вставка настроек и работа с проводами |

Для группы можно выбрать:

- **Как для остальных** — использовать строку «Остальные группы» этой зоны.
- **Не ограничивать** — зона не добавляет запрет на это действие.
- **Запретить** — действие запрещено внутри этой зоны.

Строка «Остальные группы» применяется также к новым группам, созданным позже.
Настройки привязаны к ID группы: переименование не сбрасывает права, удаление
группы удаляет её правила зоны.

**Общие запреты Factorio всегда сохраняются.** «Не ограничивать» не выдаёт игроку
право, отсутствующее у основной группы. Например, строителям разрешено строить
глобально, но зона склада может запрещать им строительство и демонтаж, оставляя
доступ к содержимому сундуков.

При пересечении активных зон запрет любой зоны побеждает. Вложенная разрешающая
зона не отменяет запрет внешней. Проверяется поверхность и место действия/объекта,
а не положение персонажа.

## Отдельные настройки зоны

- **Защищать объекты от любого урона** — общая неуязвимость для всех групп.
  Она предотвращает урон и не восстанавливает здоровье задним числом.
- **Не ограничивать администраторов** — обход правил именно этой зоны для игроков
  с настоящим статусом администратора. Общие запреты группы и неуязвимость сохраняются.
- **Разрешить роботам строительство / демонтаж** — независимые правила роботов.
  По умолчанию оба действия запрещены. Роботу не приписывается группа случайного
  игрока той же силы.

Для выдачи игроком приказа демонтажа роботами нужны и права его группы, и разрешение
демонтажа роботами во всех затронутых зонах. Обновление требует прав строительства
и демонтажа. При запрете существующие приказы в зоне отменяются, включая задания
уже вылетевших роботов.

Заблокированное строительство возвращает реально потраченные предметы, сохраняя
качество и данные. Переполнение выкладывается на землю. Призраки не расходуют
строительный предмет и не создают возврат.

## Управление

- `/zone-tool` — получить инструмент, только администратор.
- `/zone-gui` — открыть управление и права, только администратор.
- `/show-zone` — ненадолго показать все зоны, только администратор.
- `/list-zones` — вывести список зон.

В GUI можно показать, отключить, включить и удалить зону. Отключение/удаление
восстанавливает исходные свойства объектов с учётом оставшихся зон. Старые объекты
без сохранённых свойств мод не пытается исправлять наугад.
После снятия статуса админа оставленное открытым окно не даёт менять зоны.
Устаревшие настройки не перезаписывают изменения другого администратора.

## Технические особенности

Для ручного демонтажа и взаимодействия игрок временно переводится в служебную
группу `[Zone Permissions] <ID основной группы>:<маска>`. Она копирует общие права
основной группы и добавляет запреты для выбранного объекта. При смене объекта
исходная группа восстанавливается; изменения общих прав учитываются сразу.

В редакторе зон служебные группы скрыты. В `/permissions` назначайте игроков в
обычные группы и редактируйте права у них. Перед отключением или удалением мода
отключите все зоны через GUI: мод вернёт всех игроков в основные группы и удалит
служебные группы, включая группы отключённых игроков.

## Границы первого этапа

- Ограничения относятся к объектам. Укладка/добыча покрытий земли и применение
  капсул пока не входят в эти три права.
- Обычная вставка настроек блокируется по выбранному объекту. Наложение большого
  чертежа на существующие здания ещё не защищает все их настройки; размещение
  новых призраков проверяется по каждому объекту.
- Скриптовые команды администратора и изменения другими модами могут обходить
  ограничения ввода.
- Транспорт, пересекающий границы, пока не отслеживается непрерывно для неуязвимости.
- Проверено в Factorio 2.1.24 в изолированном режиме. Два одновременно подключённых
  сетевых клиента отдельно не тестировались.

## Дальнейшие планы

- Ножницы для редактирования границ и вырезания свободных участков.
- Права для покрытий, капсул и остальных способов изменения объектов.
- Дополнительная защита настроек при наложении чертежей.
- Чёрный список типов объектов, например транспорта.
- Названия зон, журнал действий, импорт и экспорт настроек.

## Разработка

`control.lua` — события и жизненный цикл зон; `permissions.lua` — правила и
эффективные группы; `zone-gui.lua` — интерфейс. `control.txt` — неиспользуемый старый
набросок, который игра не загружает. Данные сохраняются в `storage`.
Проверки и инструкция запуска находятся в `tests/` репозитория.
